<product_requirements>
The goal is to create Zeha, a global AI assistant mobile application for iOS and Android using React Native (Expo).

**Core Product:**
-   A general-purpose AI assistant capable of multilingual chat.
-   A special, optional Kids Mode for users aged 4-15, which provides a safer, filtered experience.

**Key Features:**
1.  **Authentication:**
    -   Account types: Adult (can become Parent), Guest.
    -   Kid accounts are *not* created at registration; they are created by Parents.
2.  **Parent Dashboard (PRO Feature):**
    -   Accessible only to PRO subscribers.
    -   Allows parents to create and manage up to two kid accounts.
    -   View risk/security alerts and psychological health summaries for their children (without viewing message content).
    -   Configure time settings (message limits, sleep/school hours).
3.  **Kids Chat:**
    -   Real-time, streaming chat with the AI using Server-Sent Events (SSE).
    -   Supports text, emoji, image, and voice messages.
    -   AI responses are tailored to age groups.
4.  **Subscription System (PRO Membership):**
    -   A  auto-renewable subscription (zeha_pro_monthly).
    -   Implemented using Apple IAP and Google Play Billing.
    -   Unlocks the Parent Dashboard and associated features.
    -   Includes a Restore Purchases function.

The application must be secure and compliant with regulations like COPPA.
</product_requirements>
